# SAARTHI AI


A complete, production-quality, responsive one-page agency website built for a fictional digital agency named "NorthPeak Digital".

## Features

- **Responsive Design**: Works perfectly across mobile (360px), tablet (768px), laptop (1024px), and desktop (1440px+) breakpoints.
- **Premium Aesthetics**: Features a modern, minimal design with large spacing, rounded corners (16px), soft shadows, smooth hover animations, and glassmorphism.
- **Custom Illustrations**: Built completely with HTML/CSS shapes and SVG - no stock images.
- **Sticky Navigation**: Animated navigation bar that becomes sticky and slightly translucent on scroll.
- **Mobile Menu**: Custom hamburger menu with slide animation.
- **Scroll Reveal Animations**: Elements fade in and slide up smoothly as they enter the viewport using Intersection Observer.
- **Client-Side Form Validation**: Fully functioning contact form validation with real-time feedback and success state.
- **Accessibility**: Built with semantic HTML, proper ARIA labels, focus states, and logical heading hierarchy.
- **Zero Dependencies**: Built entirely without frameworks or libraries. No Bootstrap, React, Tailwind, or jQuery.

## Tech Stack

- HTML5
- CSS3 (Vanilla, CSS Variables, Flexbox, CSS Grid, Keyframes)
- JavaScript (Vanilla, ES6+, IntersectionObserver)

## Deployment Instructions

Since this is a static website built with pure HTML, CSS, and JS, deployment is incredibly straightforward:

1. **GitHub Pages**:
   - Push this repository to GitHub.
   - Go to Settings > Pages.
   - Select the `main` branch as the source and save.
   
2. **Vercel / Netlify**:
   - Drag and drop the project folder into Netlify Drop.
   - OR connect your GitHub repository to Vercel/Netlify for automated deployments.

3. **Traditional Hosting**:
   - Upload `index.html`, `style.css`, and `script.js` to the `public_html` or `www` directory of your web server via FTP/SFTP.
